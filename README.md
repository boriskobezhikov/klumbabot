# Klumba rental monitor

Слушает Telegram-группу "Клумба" (@kkklumba) в реальном времени, дёшево
отфильтровывает нерелевантные сообщения, прогоняет кандидатов через Claude
(проверяет цену/спальни/срок аренды по вашим критериям) и присылает вам
уведомление в Telegram, когда находит подходящую квартиру.

Оценка стоимости проверок через Claude: ~$1-3/мес при обычной активности
чата (Haiku 4.5, с regex-предфильтром перед API).

## Как это устроено

Один плагин не может и читать чужую группу, и писать вам от лица бота, поэтому
тут два разных "аккаунта":

1. **Userbot** (Telethon) — логинится под вашим личным Telegram-аккаунтом
   (вы же уже состоите в "Клумбе") и молча слушает новые сообщения. Обычный
   bot API для этого не годится — ботов нельзя добавить в чужую публичную
   группу без прав администратора.
2. **Notify-бот** (обычный Telegram-бот через BotFather) — только шлёт вам
   личные сообщения с находками. Ему не нужно быть в группе.

## Установка (на вашем VPS)

```bash
sudo apt update && sudo apt install -y python3-venv python3-pip
mkdir -p /opt/klumba-bot && cd /opt/klumba-bot
# скопируйте сюда main.py, requirements.txt, .env.example, klumba-bot.service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env   # заполните все значения, см. ниже откуда их брать
```

### Откуда взять значения для .env

- **TG_API_ID / TG_API_HASH** — https://my.telegram.org → "API development
  tools" → создайте приложение (любое название). Это привязано к вашему
  личному номеру телефона, только для вас.
- **NOTIFY_BOT_TOKEN** — в Telegram напишите @BotFather, `/newbot`, следуйте
  инструкциям, получите токен вида `123456:AAExxxx`.
- **NOTIFY_CHAT_ID** — напишите что угодно своему новому боту, затем откройте
  в браузере `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите
  `"chat":{"id": ...}` — это число и есть ваш chat id.
- **ANTHROPIC_API_KEY** — https://platform.claude.com, раздел API keys,
  привяжите карту (иначе ключ не будет работать).

### Первый запуск (логин в свой аккаунт)

```bash
python main.py
```

При первом запуске Telethon спросит номер телефона и код из Telegram
(придёт в само приложение Telegram, не SMS) — введите его прямо в терминале.
Это разовая операция: она создаст файл сессии
(`klumba_userbot.session`), после чего логиниться заново не нужно.
**Никому не отправляйте этот .session файл** — он равносилен доступу к
вашему аккаунту.

Если увидите в Telegram сообщение от вашего notify-бота "✅ Мониторинг
Клумбы запущен" — всё работает. Остановите (Ctrl+C) и переходите к шагу
автозапуска ниже.

### Автозапуск как systemd-сервис (чтобы работал 24/7 и поднимался после
### перезагрузки/падения)

```bash
sudo cp klumba-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now klumba-bot
sudo systemctl status klumba-bot     # проверить, что запущен
journalctl -u klumba-bot -f          # смотреть логи в реальном времени
```

## Настройка критериев

В `.env`:
- `BUDGET_USD` — максимальный бюджет всего (аренда + коммуналка), по
  умолчанию 700.
- `GEL_PER_USD` — курс для перевода коммуналки, если она указана в лари.

Если нужно поменять сами критерии (например добавить район, площадь,
количество спален) — правьте `SYSTEM_PROMPT` в `main.py`, это обычный
текст на русском, Claude поймёт любые формулировки.

## Ограничения

- Ловит только НОВЫЕ сообщения, появившиеся пока бот запущен (это
  устроено через live-подписку на события, а не через опрос раз в час —
  так что задержка между постом и уведомлением обычно секунды).
- Пока бот выключен (упал VPS, перезагрузка без автозапуска и т.п.) —
  пропущенные за это время объявления не восстанавливаются.
- Claude может иногда ошибаться в классификации (как и любой человек,
  бегло читающий объявление) — это фильтр для экономии времени, а не
  гарантия не пропустить вообще ничего.
